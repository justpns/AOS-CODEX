01 / Design intent

Tome

เปลี่ยน Skill behavior และ rotation โดยมี opportunity cost จากช่อง Tome

Card

เสริม synergy เฉพาะทางและแข่งขันกับ Card เดิมใน slot เดียวกัน

Gem

เสริม modifier เฉพาะ mechanic โดยไม่เพิ่มพลังทุกด้านพร้อมกัน

Proposal IDItem / TypeClass / Slot / BuildProposed effectValidation

03 / Developer handoff

Data contract

proposalId, itemType, name, class / slot / build, effect, status. Production item ID, rarity, drop source, modifier keys และ localization: TBD.

Combat rules — TBD

กำหนด trigger, eligible hit, chance, ICD, stack cap, duration, refresh, damage bucket, PvP rules และ interactions ก่อน implementation.

Safety constraints

ห้าม proc เรียกตัวเองซ้ำโดยไม่มี guard; จำกัด AoE และ summon triggers; ระบุว่า bonus ใช้กับ owner หรือ summon; หลีกเลี่ยง double dipping.

04 / Review & acceptance

□ ตรวจชื่อและ effect ซ้ำกับ Codex ล่าสุด
□ ตรวจ skill ID, class eligibility, equipment slot และ Gem row ที่รองรับ
□ นิยามสูตรและเงื่อนไขที่ยังไม่ชัดเจน เช่น HP cost, status penetration, AoE radius และ barrier
□ เทียบ DPS, sustain, AoE และ utility กับ build เดิมที่ระดับลงทุนเท่ากัน
□ ทดสอบ multi-hit, auto-cast, summon, DoT, reflected damage และ boss/PvP rules
□ ผ่าน balance review ก่อนกำหนด rarity, drop source และ release

05 / Provenance & limitations

ฐานแนวคิด: Build Codex v8 — Peer Tiers & Class Freedom และรายการ Future Items 63 รายการที่สรุปไว้ในบทสนทนา. ตรวจชื่อ Tome/Card แบบ exact match กับไฟล์ tomes.json และ cards.json (8 Nov 2026) เท่านั้น ไม่ใช่การตรวจ effect ซ้ำหรือสถานะ live server. ไม่มี standalone Gem catalog ที่ยืนยันได้ จึงยังไม่ตรวจชื่อ Gem. ไม่รวม Tome ที่มีอยู่แล้วแต่ไม่ระบุแหล่งดรอปเป็นรายการใหม่. ทุกค่าเป็น proposal และยังไม่ได้ทดสอบ balance.
